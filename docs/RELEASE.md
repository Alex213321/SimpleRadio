## Release 页面建议文案

SimpleRadio 1.4.2：离线沉浸式音乐播放器。完整源码公开，支持二次开发；成品无需 Node.js、npm 或 Electron 环境。

请同时下载 Program 和 Music 两个 ZIP，把两个包解压到同一位置，让内部 `SimpleRadio-1.4.2` 文件夹合并，然后运行其中的 `SimpleRadio.exe`。只下一个包无法获得完整体验。

仓库的 Download ZIP 和 Release 自动附带的 Source code 下载的是源码，不是播放器成品。完整教程和六张界面预览见仓库首页。
